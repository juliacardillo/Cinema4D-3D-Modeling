This repository includes some 3D modeling work I've done, specifically in Cinema4D. 

Please note that some of the files I've included are at least 4 years old, and so I've sadly lost the texture files for some of them. I've included a rendering photo that I had on hand, when possible. 

* The Crab I made following a tutorial, it is animated if you open the actual C4D file!
* For the Modern House, I made it entirely from using a reference photo of a modern house off of Google.
* For the Caterpillar, I also modeled it entirely from using a reference photo of an Anise Swallowtail Caterpillar on Google.
